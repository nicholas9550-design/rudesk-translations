# ruDESK 🇷🇺

Русские переводы для Nextcloud и его приложений. Делал для собственного
использования — делюсь, вдруг пригодится кому-то ещё.

Переводы подготовлены с помощью AI. Возможны ошибки и неточности.
Предоставляются «как есть», без гарантий совместимости и поддержки.
Перед использованием сделайте резервную копию.

Здесь только [словари](translations/draft-ruDESK/), готового установщика
пока нет. Это независимый проект, не официальный перевод Nextcloud.

🔧 [Как мы подключаем переводы](USAGE.md)

Права на исходные материалы сохраняются за их авторами. Условия
распространения зависят от лицензий соответствующих приложений.

Нашли неточность? Напишите в [Issues](https://github.com/nicholas9550-design/rudesk-translations/issues).
