# Как мы подключаем переводы 🔧

Наш метод: отдельное приложение Nextcloud подключает нужный словарь
на странице приложения. Штатные файлы не заменяются, язык остаётся `ru`.

## Мини-пример

В [examples/rudesk_example/](examples/rudesk_example/) — учебный загрузчик
одной строки для **Nextcloud 34 и Tables 2.3.2**:

```js
OC.L10N.register('tables', { Total: 'Всего' });
```

Он работает только на странице Tables, после входа и при русском языке.
Это сокращённый пример нашего подхода, не копия рабочего загрузчика.
PHP-синтаксис, ветвления на заглушках и регистрация JS проверены локально; установка и работа
этого примера в браузере пока не проверены.

## Как попробовать на тестовом сервере

1. Убедитесь, что установлены указанные версии. Сделайте резервную копию.
2. Поместите папку `rudesk_example` в разрешённый **записываемый каталог
   собственных приложений** Nextcloud. В Snap путь зависит от установки;
   ничего не копируйте в `/snap/nextcloud/…`.
3. Через штатный `occ` вашей установки выполните:
   `occ app:enable rudesk_example`.
4. Откройте Tables с русским языком и обновите страницу.
   В инструментах разработчика проверьте загрузку `example-l10n.js`
   и метку `document.documentElement.dataset.ruDeskExample`.
5. Откат: `occ app:disable rudesk_example`, затем обновите страницу.

В Snap команда `occ` обычно вызывается как `sudo nextcloud.occ`.
Не применяйте пример сразу на рабочем сервере.

Для полного словаря можно заменить содержимое `js/example-l10n.js`
файлом `translations/draft-ruDESK/extra-apps/tables/l10n/ruDESK.js`.
Сначала сверьте ключи с вашей версией Tables. Пример ограничен версией
2.3.2 намеренно: снятие этой проверки не подтверждает совместимость.

## Границы метода

Поздняя загрузка штатного словаря может заменить наши строки:
порядок и результат нужно проверить в браузере. Письма, PHP-тексты,
сохранённые шаблоны и другие приложения этот пример не переводит.
После обновлений нужна повторная проверка. Материалы — «как есть»,
без гарантий; условия использования приведены в [README](README.md).

Код учебного примера — AGPL-3.0-or-later, текст в его файле `COPYING`.
Это не меняет условия распространения самих словарей.
